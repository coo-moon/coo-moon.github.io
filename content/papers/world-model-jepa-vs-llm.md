过去几年，大语言模型几乎定义了人工智能的发展方向。从 GPT 到 Claude、Gemini，再到各种开源模型，主流路线非常清晰：收集海量文本，用自监督学习训练一个巨大的 Transformer，让模型预测下一个 token。

随着参数、数据和算力不断增加，模型展现出写作、编程、推理、对话等能力。但 Yann LeCun 对这条路线始终持强烈怀疑态度。在他看来，LLM 可能是非常有用的工具，却未必是通往真正智能的终点。

人类在学会说话之前，就已经能够理解物体、空间、因果、行动和结果。语言可能是智能的表达方式，却不一定是智能的来源。

LeCun 提出的另一条路线，是以“世界模型”为核心，以 JEPA（Joint Embedding Predictive Architecture，联合嵌入预测架构）为代表的非生成式学习方法。

## LeCun 为什么怀疑 LLM 是终点？

### 语言不是现实世界本身

LLM 的主要训练目标是预测文本中的下一个 token。给定“小球从桌子边缘掉了下去，接下来它会……”，模型可以预测“落到地上”。但这不等于它真正理解了重力、物体、空间关系和运动轨迹，它也可能只是学会了人类通常如何描述这类事件。

文本是现实世界的投影，而不是现实世界本身。大量关于物理世界的信息，从来不会完整地出现在语言中：物体的连续运动、三维空间关系、遮挡后的物体仍然存在、手部动作对物体的影响，以及一个计划失败后如何调整。

### LLM 不天然拥有持续的世界状态

人类会不断更新自己对世界的内部理解。看到一个杯子，即使它暂时被书挡住，也不会认为杯子消失了。我们会推断它的位置、重量和材质，并预测移动它之后会发生什么。

这是一种持续运行的内部世界模型。而传统 LLM 更像是一次次完成输入到输出的映射：它可以谈论世界，却不一定拥有一个稳定、持续更新的世界状态。

### 语言上合理，不等于现实中正确

LLM 的目标是生成概率上合理的序列，而不是保证陈述与现实一致。因此，只要某段话在语言上听起来合理，模型就可能生成它，即使事实并不存在。这就是幻觉问题的结构性来源之一。

### 生成计划，不等于执行计划

LLM 可以写出“打开柜门、找到杯子、倒水、放到桌上”的计划，但真正的智能体还必须知道柜门是否打开、杯子是否在那里、水是否已经倒满，以及下一步会不会打翻杯子。

这要求模型预测行动对世界的影响，而不只是生成一段看起来合理的文字。

## 什么是世界模型？

世界模型可以简单理解为：一个能够描述世界状态，并预测行动后世界将如何变化的内部模型。

假设智能体看到桌子、杯子、手和一瓶水。世界模型不仅要识别这些对象，还需要理解它们之间的关系：杯子位于桌面上，手可以抓住杯子，水会从瓶子流入杯子，杯子太满可能会溢出。

更重要的是，它需要回答反事实问题：**如果我执行这个动作，接下来会发生什么？**

识别模型回答“现在看到了什么”；世界模型进一步回答“世界为什么是这样、它接下来会怎样、如果我采取某个行动会发生什么”。

## JEPA：不预测像素，而是预测意义

JEPA 的关键思想，是不要试图重建输入中所有细节，而是预测被遮挡部分的抽象表示。

以图像为例，模型可以看到上下文区域，却看不到目标区域。它不直接生成目标区域的每一个像素，而是预测目标区域在表示空间中的 embedding：

$$z_{target} \approx P(z_{context})$$

其中，$z_{context}$ 是上下文的抽象表示，$z_{target}$ 是目标区域的抽象表示，$P$ 是预测器。

模型关心的不是“目标区域的每一个像素究竟是什么”，而是“根据已经看到的内容，目标区域在语义上应该具有什么特征”。

如果一块区域里有树叶、阴影和反光，精确像素本身可能不可预测；但物体身份、位置、运动方向和场景结构通常更稳定。JEPA 试图忽略不可预测的细节，重点学习有价值的信息。

## 从 I-JEPA 到 V-JEPA

### I-JEPA：从图像学习结构

I-JEPA 会遮挡图像中的大片区域，让模型根据可见区域预测被遮挡区域的高层表示。

人类看到一张被遮挡的椅子，不需要在脑中生成每一根木纹，仍然可以判断那是一把椅子，并推测它的完整结构。I-JEPA 的意义就在于：模型可以在没有文字标签的情况下，通过图像自身学习有用的视觉表征。

### V-JEPA：从视频学习变化

单张图像只能告诉模型“世界是什么样”，视频则提供“世界如何变化”。V-JEPA 通过遮挡视频中的空间—时间区域，让模型根据上下文预测目标区域的表示。

当视频中出现小球滚动、手拿起杯子、汽车转弯或物体从桌边掉落时，模型不需要生成每一帧的全部像素，却需要预测未来状态的抽象表示。通过这种方式，它有机会学习物体连续运动、遮挡后的持续存在，以及动作与结果之间的规律。

与视频生成模型相比，V-JEPA 不必逐帧生成逼真的画面，而只预测世界状态中更稳定、更可预测的部分。

## JEPA 与 LLM 的区别

| 维度 | LLM | JEPA / 世界模型 |
|---|---|---|
| 主要输入 | 文本 token | 图像、视频、感知信号 |
| 训练目标 | 预测下一个 token | 预测未知区域的抽象表示 |
| 关注对象 | 语言序列 | 世界状态与状态变化 |
| 是否直接生成内容 | 是 | 通常不是 |
| 主要能力 | 语言理解与生成 | 感知、预测与规划 |
| 典型问题 | 幻觉、长链条规划不稳定 | 语义表达、行动建模仍不成熟 |

LLM 的核心问题是：“下一句话最可能是什么？”世界模型的核心问题是：“世界现在处于什么状态？如果采取行动，接下来会发生什么？”

## H-JEPA：分层理解世界

一个真正有用的世界模型不能只有单一时间尺度。人类会同时预测：几百毫秒后手该移到哪里，几秒钟后物体处于什么位置，几分钟后任务能否完成。

因此 LeCun 设想了 H-JEPA（Hierarchical JEPA，分层 JEPA）：低层模型负责细节、短时间尺度和快速反馈；高层模型负责抽象状态、长时间尺度、任务目标与复杂计划。

比如机器人要把杯子放进柜子：低层模型预测手如何移动、如何抓住杯子；高层模型则规划拿起杯子、打开柜门、移动到指定位置并放下。

这与模型预测控制的思想相近：先在内部模拟不同的行动序列，再选择最有可能完成目标的一组动作。

## “LLM 是死胡同”应该如何理解？

LeCun 并不是说语言模型没有价值，也不是说 Transformer 不应继续发展。更准确的理解是：**仅仅沿着“更大的语言模型、更多文本和更强算力”这条路线，可能无法自然地产生完整的通用智能。**

LLM 可以负责语言交流、知识检索、任务描述、高层指令理解和人机协作。但一个完整的智能体还需要感知、世界模型、记忆、预测、规划、行动，以及能够从现实反馈中学习的机制。

语言模型更像其中的语言接口，而不是整个系统。

## JEPA 路线的难点

JEPA 很有吸引力，但它还不是完成的通用智能方案。

1. **表示空间应该包含什么？** 抽象得太少会丢失关键细节，抽象得太多又会回到重建所有观测。
2. **如何与行动结合？** 世界模型必须预测“执行某个动作之后，状态会如何变化”。
3. **长期预测仍然困难。** 每一步的小误差在连续滚动后仍可能累积。
4. **如何学习因果关系？** 观察到“伸手后杯子移动”并不等于理解了接触导致移动。
5. **如何与语言融合？** 世界模型擅长现实 grounding，LLM 擅长语言与抽象知识，二者更可能互补而非互斥。

## 两条路线最终可能汇合

未来的智能系统可能同时包含：视觉和视频世界模型、语言模型、规划器以及执行模块。

LLM 回答“人类想做什么”；世界模型回答“这样做之后世界会发生什么”；规划系统回答“应该采取哪些步骤”；执行系统回答“现在具体怎么做”。

语言不再是智能的全部，而是连接人类意图与世界模型的接口。

## 结语：从会说话到理解世界

大语言模型已经证明，预测语言可以产生惊人的能力。但会生成语言，不等于真正理解世界；能够描述计划，也不等于能够在现实中执行计划。

LeCun 的 JEPA 路线提出了一个重要提醒：**智能的核心，也许不是生成更多内容，而是学习一个能够预测世界变化的内部模型。**

从 I-JEPA 到 V-JEPA，JEPA 距离长期预测、主动规划、因果理解和现实控制仍有很长的路。但它代表了一个值得认真对待的方向：人工智能不应只学习“人类如何谈论世界”，还应该直接从视觉、行动和反馈中学习“世界本身如何运行”。

如果说 LLM 让机器学会了如何使用语言，那么世界模型路线试图让机器学会：**世界是什么，它为什么这样变化，以及我怎样才能改变它。**

这也许正是下一阶段人工智能竞争的核心：不是谁能生成更多 token，而是谁能建立更可靠、更可解释、能够服务于行动的世界模型。

LLM 让机器更像一个博学的语言使用者；JEPA 则试图让机器成为一个能够观察、预测和行动的智能体。二者并非必然对立，但如果目标是通用智能，仅靠语言的统计规律，可能远远不够。
