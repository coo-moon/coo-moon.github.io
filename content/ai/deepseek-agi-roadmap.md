# 梁文锋的 AGI 路线图：从思维链到自我迭代奇点

> 2026 年 7 月，一段 DeepSeek 创始人梁文锋在 5 月 20 日投资人闭门会上的近 4 小时录音流出，引发全网刷屏。这不是一场融资路演，而是一份罕见的、完整的 AGI 技术路线图：**语言模型 → 思维链 → Agent → 持续学习 → 自我迭代奇点 → 具身智能**。本文拆解这条路线，并解释它为什么值得每一个 AI 学习者认真对待。

---

## 一、开场：一个"不赚钱"的 AI 公司

梁文锋在会上的很多话，放在商业语境里几乎是"反常识"的：

- 公司"没有 KPI、没有组织架构、没有成文愿景"，靠"对世界的善意"和"对 AGI 的执念"凝聚团队
- API 定价只求**十个月收回设备成本**，不追求利润最大化
- "做成下一个字节、下一个腾讯？完全没有这样的想法。不争这个东西，是因为**后面还有西瓜，前面的可能都是芝麻**"
- 产品只是"AGI 路上的副产物"，不需要投入太多心思做 C 端、B 端

但如果你把它放在"以 AGI 为唯一目标"的坐标系里，这些决策全是理性的：

> "我毫不怀疑 AGI 会有非常大的商业价值。在这个基础上，我优先考虑的不是多拿份额，而是**增加做成的概率**。你越克制，就越有可能做成这件事。"

"克制是一种战略"——这是理解 DeepSeek 一切选择的钥匙。

## 二、路线图总览：五级阶梯

梁文锋用"爬楼梯"来比喻 AGI 的实现路径：

| 阶梯 | 内容 | 状态（2026 年中） |
|------|------|------------------|
| 第 1 级 | 语言模型 | ✅ 已完成 |
| 第 2 级 | CoT 思维链（Chain of Thought） | ✅ 已完成（2025 年的阶梯） |
| 第 3 级 | Agent 智能体 | 🔄 进行中（2026 年的阶梯） |
| 第 4 级 | **持续学习** | 🎯 当前核心攻坚 |
| 第 5 级 | 自我迭代奇点（AI 加速 AI 研究） | ⏳ 渐进式突破 |
| 终点 | 具身智能 | 🌅 "智能的终点可能都是具身" |

> "去年的阶梯是 CoT，今年的阶梯就是 Agent。在 Agent 之后要解决的问题就是持续学习。"

每一级都是下一级的前提，跳过任何一级都会失败。下面逐级拆解。

## 三、前两级：语言模型与思维链（已完成）

**语言模型**是地基——让机器学会"理解与生成自然语言"，DeepSeek 通过 V3 系列完成了这一步。

**CoT 思维链**是 2025 年的阶梯，代表作品是 **DeepSeek-R1**。R1 的突破不在于"会推理"，而在于证明了推理能力可以不依赖人工标注的思维链模板：

- R1-Zero：完全抛开预设思维链和监督微调，**仅靠强化学习的奖惩信号**，让模型自己"涌现"出推理行为
- 训练成本不到行业均值的 10%

这一步的深层意义是：**推理不是教出来的，是"长"出来的**——给对奖励，模型会自己找到思考的方式。这为后面的"自我迭代"埋下了伏笔。

## 四、第三级：Agent——"今年的阶梯"

2026 年，DeepSeek 的主线是 Agent。梁文锋给出了两个关键判断：

**1. Coding Agent 是当前最重要的方向。** 编程是少数"反馈闭环极短、验证成本极低"的任务——写错立刻报错，改对立刻通过。这种环境最适合模型自我纠错、积累能力，是通往通用智能的最佳训练场。

**2. 在中国做通用 Agent，不做垂直 Agent。** 金融、医疗等垂直领域 Agent 优先级较低。逻辑是：垂直 Agent 的天花板被领域知识锁死，而通用 Agent 的能力可以复用到一切任务——先有通用的"能力底座"，垂直场景只是插槽。

> "我们做的模型，第一目标不是大家用得好用，而是**我们自己用得好用**。这是实现 AGI 最快的方法。"

这句话值得细品：DeepSeek 把自家模型当第一个重度用户，让模型在真实研发流程里被反复使用、暴露问题、迭代升级——**模型即产品，产品即训练场**。

## 五、第四级：持续学习——真正的分水岭 ⭐

这是整场会议信息量最大、也最被低估的部分。

### 当前 AI 的最大缺失

> "人类可以持续积累经验，但目前 AI 需要输入完整上下文才能完成任务，这限制了 AI 替代人类工作的能力。**下一代模型必须要有持续学习的能力，才能叫下一代模型**。"

细想一下现在的 AI 工作方式：每次对话都是"失忆"的——你教会它你的项目背景，下次它又忘了；模型训练完就冻结，世界变了它不知道。这就像一个永远无法积累经验的实习生：每次都从零开始读文档。

### 技术难点：灾难性遗忘

持续学习在学界是个"老问题"：神经网络在学习新知识时，会**覆盖掉旧知识**——这叫灾难性遗忘（Catastrophic Forgetting）。人类不会学了新语言就忘了母语，但神经网络会。

DeepSeek 的方向是给模型装上"**选择性记忆机制**"：像人一样，知道什么该记、什么该忘、什么该长期沉淀。这比"把上下文窗口做长"难得多——**上下文是"临时记忆"，持续学习是"长期记忆 + 主动复习"**。

### 为什么这是分水岭

因为持续学习一旦实现，后面两级就是水到渠成：模型能在使用中积累经验 → 经验转化为能力 → 能力反哺自身研发 → 自我迭代奇点。

这也是为什么 DeepSeek **明确砍掉了 3D 生成、视频生成、世界模型**：多模态"只是一个组件，不是主线和智能本身"；连幻觉问题都被归类为"产品问题，会去解决，但不是重点"。**所有资源集中在一条主线上**——这又是"克制"的体现。

## 六、第五级：自我迭代奇点

> "实现持续学习之后，可能迎来一个**渐进的奇点**——模型可以完成人类能做的所有事情，包括自己开发更前沿的模型，即 **AI 加速 AI 研究**。"

注意关键词：**渐进**。梁文锋认为这不会是某个早晨突然降临的"奇点时刻"，而是一个逐步突破的过程：模型先能完成更多人类工作 → 再能辅助研发 → 最后自己研发下一代模型。

一旦 AI 能参与自身研发，研发速度就脱离了人类带宽的限制——这是指数级的开始。而 DeepSeek 已经在为这一天布局：R1 的开源、模型的"自用优先"、对 Coding Agent 的押注，全部指向同一个终点。

## 七、终点：具身智能

> "走完这一步，才是具身智能。**智能的终点可能都是具身**。"

理解这句话的关键：智能不只是"思考"，还要在物理世界里**验证和交互**。没有身体的智能像没有手脚的棋手——能算棋，不能下棋。具身智能让 AI 通过物理世界的反馈继续学习，形成"感知 → 决策 → 行动 → 反馈 → 再学习"的完整闭环。

这也是为什么 DeepSeek 虽然现在砍掉了世界模型，但把它放在路线的终点——**不是不要，是顺序问题**：先有持续的认知能力，再谈物理世界。

## 八、配套战略：开源、算力与组织

### 开源不是情怀，是算过的账

> "AI 这个事情足够大，最终它可能得占人类社会 GDP 的百分之十。一个人独占这个事情……你一定得跟别人分享，否则你肯定活不下来。"

开源让 DeepSeek 获得全球开发者的免费反馈、生态共建和人才吸引力——用让渡一部分利益，换整体生态的繁荣，再反哺自己的技术路线。

### 算力现实：用 1/20 的算力追赶

- DeepSeek 拥有约 **两万张 H 等效算力**，落后美国 **12 到 18 个月**
- 梁文锋判断：中美差距本质是**算力差距，而非人才差距**
- 国产芯片"生态没问题，产能是瓶颈"；与华为合作开发**昇腾 950** 生态
- 判断 **CUDA 生态护城河正在瓦解**——软件栈会追平硬件差距

这套判断解释了 DeepSeek 为什么在算法效率上如此激进：**算力不够，只能拿算法来凑**——而算法创新反而成了它的护城河。

### 组织：团队稳定是"唯一不可退让的核心利益"

> "只要团队稳定，AGI 就一定能做成。"

- 员工一半时间自由探索，不强制加班——"做研究需要松弛的环境，你逼得很紧，就没法做研究"
- 公司决策建立在共识基础上，而非个人指令
- 随着规模扩大（500 亿+ 融资、腾讯/宁德时代/京东/网易等入局），部分部门开始建立层级，研究部门仍保持扁平

在梁文锋的框架里，技术路线可以调，商业节奏可以慢，**唯独团队不能散**——因为 AGI 是一场以十年为单位的持久战。

## 九、对学习者的启示

这条路线图不只是 DeepSeek 的公司战略，它对个人学习路径也有直接的参考价值：

| DeepSeek 的阶梯 | 对应的个人能力 |
|----------------|---------------|
| 语言模型 | 理解模型原理（Transformer、训练、微调） |
| CoT 思维链 | 提示词工程、推理能力、RAG |
| Agent | **工具调用、MCP、Agent 开发**——当下性价比最高的技能 |
| 持续学习 | 系统学习方法论，让知识沉淀而非遗忘 |
| 自我迭代 | 用 AI 辅助自己学习 AI（AI 加速 AI 学习） |

尤其是 **Agent 开发**——DeepSeek 判断这是"今年的阶梯"，也是个人学习者目前最容易切入、反馈最快、最贴近实战的方向。与其等 AGI 降临，不如先成为会用 Agent 的人。

## 十、总结

> **语言模型 → 思维链 → Agent → 持续学习 → 自我迭代 → 具身智能**

梁文锋的 AGI 路线图，本质上是一份"**能力的递进清单**"：每一级解决上一级暴露出的瓶颈——语言模型缺推理，就上 CoT；CoT 缺执行，就上 Agent；Agent 缺经验积累，就上持续学习；持续学习到位，自我迭代水到渠成；而智能的最终形态，必然走向具身。

最值得记住的不是路线本身，而是背后的方法论：**把资源集中在一条主线上，砍掉一切非核心方向，用"克制"换"概率"**。在一个所有人都在追风口的时代，这种"只做一件事"的定力，本身就是稀缺能力。
